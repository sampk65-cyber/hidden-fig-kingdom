# V16.1 — 尋寶獎項清理與流光晶塔循環淡化

## 已確認來源
V16 的一般寶箱仍透過 COUPON_W 隨機發出 9 折、85 折、8 折、免運券，與寶箱追逐賽獎池無關。共同入口涵蓋巡園、劇情、黑騎士、每日徽章、圖鑑、家庭親密度、我的樹採收。

## 修正
- 一般寶箱統一使用原本的 +6 果友值備援獎勵，保留各活動原有額外點數。
- 移除舊隨機折扣權重、手機 luckyCheck 及伺服器 lucky 額外免單抽獎。
- 後台附贈寶箱不再提供 9 折、85 折、8 折；前後端禁止建立這些新券及未知券種。
- 已發出的舊券與紀錄保留顯示／核銷；舊公告或私訊的停用券不消耗領取標記，提示聯絡農場。
- 寶箱追逐賽仍完全依後台 config/pool 發放；免單、折 200、免運、自訂咖啡等設定、剩餘數量及週期不變。
- 採果剪既有等級保留；失去折扣效果後暫停收費升級。
- 流光晶塔音樂每次原生循環依播放時間淡入 2 秒、淡出 3 秒，中段音量仍 .32。原音軌未重壓，石磨音檔與觸發不變。

## 驗證
104 項 Node 測試通過，包含新獎勵限制、退役 gift 不消耗標記、工具升級保護、每輪淡化、Web Audio 與 media 音量路徑、音樂開關／離開清理、獎池跨日額度與城堡功能。兩頁內嵌 JS 語法檢查通過。獨立覆核發現的兩項問題已修正並補回歸測試。

## Firebase 獨立發布待辦
firestore.rules 已改為禁止手機直接建立任何新券；伺服器 Admin SDK 仍可發放後台預設獎品。Vercel 不會部署此規則，目前 Firebase 控制台要求登入，因此規則尚未套用。未重新整理的 V16 舊頁面仍可能依舊規則發折扣券，更新頁面後則使用 V16.1 點數規則。README 已標示此待辦，不冒稱規則已發布。
