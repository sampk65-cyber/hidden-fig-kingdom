# V15.18 — 吊橋守護雕像

基準：V15.17，9287988bab6a1c0beb7e8f445b39be8ba1e5ef70。

依使用者圖片，將原本吊橋密語石替換為持矛盾牌、踏伏龍的青銅天使雕像。使用參考圖生成透明素材，壓為 256×384 WebP（29,306 bytes），在地圖顯示 20×30 單位，靠入口側邊；透明點擊區為 44×44。移除原石頭路徑與外觀，操作與提示文字統一為守護雕像。

密語維持現行自動核發：前三名首次驗證點雕像後按「領取我的一次性密語」，由伺服器產生本人六位密語，10 分鐘有效，成功驗證後立即作廢。此版只更換入口美術、名稱與版本快取，沒有新增後台手填密碼功能，也沒有更改既有核發／排名與會員資料。
