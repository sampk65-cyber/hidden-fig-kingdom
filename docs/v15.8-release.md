# V15.8 — 原創音樂與成熟溫室內景

使用者已要求將音樂及場景同步到最新版本。以 V15.7 為正式基準，整合 PR #5 音樂功能及指定的樹高調整。

## 原創音樂

12 首、七種曲風、三難度共 36 組固定譜面；詳見 rhythm-music-notes.md 與 rhythm-validation.md。保留原本獎勵、正式難度進度及聲音設定。獨立審查的兩項音訊生命週期問題已以回歸測試修正。

## 溫室內景

參考使用者 1000026008.png 的成熟高樹景觀，翡翠巡園固定使用採收期成熟樹形，其餘五座溫室依既有輪作階段切換；進入採收期時使用相同的成熟視覺高度。

原先翡翠也使用 z6.stage，因此會隨輪作顯示剪枝或座果低樹。原 mature sprite 的 max(2.6, 2.0×1.15) 亦抵銷了翡翠放大倍率。現在以獨立內景階段解析及共用成熟高度解決；圖片與備援程式繪圖使用同一高度。

視覺預覽後將成熟樹高設為 4.2 個場景座標單位，使樹冠靠近現有棚架，同時維持圖像比例與中央走道。這是繪圖比例，沒有改變 stageTree 的真實階段資料（採收仍為 2.6）、生長週期、各期輪替、管理設定、尋寶碰撞範圍、位置與獎勵。剪枝、座果、度冬的一般溫室外觀保持原樣。

未更換任何圖片素材。其他遊戲、天氣、後端與 Firebase 不變。

## 驗證

- 既有 55 項回歸、新音樂 4 組測試、溫室高度 5 組測試。
- 實際場景繪圖函式的隔離 Chromium 檢查：翡翠固定成熟、一般溫室四階段切換、儲存階段不變。
- 音樂瀏覽器音訊/操作與完整結算測試。
- 內嵌 JavaScript 語法檢查；允許範圍外程式逐字比對。
- 發布後另核對正式站 HTTP 回應、版本號與檔案雜湊。瀏覽器測試不等同實體手機測試。
