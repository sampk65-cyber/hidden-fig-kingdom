# V15.21 第一關、限量通關 VIP 與關卡獎項

基準 main 7382437f84ce9e83ae4634e8cbf104186e9123c3（V15.20）。使用者明確要求實作。

四層流光晶塔，每層三扇彩窗依序停燈，只有面積最大且完整的主窗與柱上小錦旗同色才開層。障眼窗不影響判定；失敗可重試目前樓層。每色停留4秒，降低閃爍並保留判斷時間。伺服器保存進度與驗證停止時刻、順序及資格。

使用者在實際預覽後認為程序式3D過度簡化、與原圖不同；因此正式方案改為原插畫分層互動，保留精緻建築、材質及雲海，另外繪製窗光、柱上錦旗、轉輪輸入及會員角色行走。原來的WebGL/軟體三角形模型不作為正式畫面。

會員過關由後端交易核發每人每關唯一一張 VIP，限量預設100，可後台調整0..10000且不得低於已發卡數。使用唯一卡片文件與共用計數交易，重試、併發、重玩不重複發卡。缺額時保留完成資格，可後續領卡。卡含關卡縮圖、會員顯示資料及序號，不含會員登入密碼或恢復QR。

後台新增隱花之巔關卡獎項。每張新卡自動建立待填獎項記錄，管理畫面可填範本／逐卡獎項並綁定、核驗兌換；伺服器檢查 admins/uid，管理員不需要會員PID。會員卡收藏可讀最新獎項並下載卡片。所有新紀錄只寫srv，不更動Firestore規則或既有會員、抽獎API。

驗證紀錄：後端與舊城堡50個測試通過；VIP渲染6個語意測試通過（資料顯示、HTML跳脫、登入秘密排除、安全素材路徑、狀態及核驗連結）。完整回歸90項通過。隔離瀏覽器已完成四層逐窗停燈、停錯重試、人物登階、VIP自動生成、後台待填表單、獎項綁定與會員收藏同步；畫面已核對為原圖分層版本。獨立審查指出限量0顯示及儲存中表單編輯競爭，皆已修正；一般會員無權管理或兌換獎項、後端交易無額外重大問題。
