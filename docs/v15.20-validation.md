# V15.20 — 夜間守護雕像照明

基準：V15.19，f5977529602c6500587f3f80521384d5ec2b79fe。

依照使用者夜景截圖，為吊橋守護雕像加入一束柔和月白天光、雕像周圍淡金光暈與底座地面光斑，並提高夜間銅像輪廓的亮度。沿用既有 data-sky="night" 狀態，白天、清晨與傍晚隱藏光效；不新增時鐘或動畫計時器。光束與光暈 pointer-events="none"，不攔截點擊。

變更僅為 castle.js 的 SVG 繪圖、castle.css 夜景條件樣式、index.html 版本與快取，以及本紀錄。

驗證：

- 瀏覽器夜景檢視：光效顯示，雕像明亮且保留輪廓。
