# 溫室空間與節奏鼓聲修正

依使用者四項明確指令及三張圖片實作。V15.8 正式版 00cf8f1 為基準。

## 溫室
圖三是採光、比例、空間感的參考，不把整張圖片當作靜止遊戲背景。保留可行走巡園與尋寶，重新製作纖細成熟植株、清楚樹幹、正常比例無花果的透明素材；重畫藍天透光、拱頂、地面及斑駁日影。成熟樹高與樹冠寬分開設計，避免放大舊圖。
翡翠仍固定成熟，其他溫室採收期共用成熟繪圖。位置、行列、生長資料、尋寶距離、掉落、獎勵、操作和後端皆鎖定。

## 節奏
保留 12 首曲目、曲風、36 譜面、獎勵換算與正式難度進度。用原生 SVG 重畫上窄下寬、短梗、果頸、縱紋與底部果目的無花果。顯示醒目的即時累積分數、Perfect / Good / NG 判定、三項累積判定數與 COMBO。
三鍵低 / 中 / 高音鼓，按下即發聲（含空按），靜音與暫停仍有效。低鼓有低頻基音、厚實泛音與瞬態；中鼓和高鼓音高清楚可辨。背景 12 首的鼓組也強化低 / 中 / 高的層次而保留曲風。
判定沿用 90ms Perfect / 220ms Good；失誤包含錯採青果、漏接與空按的 NG 顯示，空按不另扣既有分數，低鼓不能成為全域音訊改動。高分仍由原有已命中分數換算，不能因多次亂按得到獎勵。

## 實作選擇
採用新樹木透明素材 + Canvas 空間繪圖，維持移動、視差及互動。排除只縮放舊樹圖（正是本次回報）及整張固定背景（會失去巡園互動）。節奏採原生 SVG + Web Audio，不加入外部執行套件。
上述是依明確需求作出的實作選擇；不新增遊戲、後台欄位或付費音源。

## 驗收
390×844 / 320×568 手機畫面實際截圖；比較參考的明亮空間與可見走道、上下留白；測試前行及側向移動。離線音訊驗證三鼓頻段不同且低鼓含低頻；UI 驗證 Perfect/Good/NG、累積分數、暫停與結束清理。既有回歸測試及範圍外逐字比對。實體 Android 與喇叭聽感不得冒稱已測。
