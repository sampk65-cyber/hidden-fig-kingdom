# V15.17 — 翡翠溫室鋼絲與固定線

基準：V15.16，9b9686a903269498e3cb5148e068fdfce9f7d4d1。

依使用者照片，翡翠左右各五排植物上方新增頭尾貫穿的細鋼絲（每排一條），每棵已繪製植物由鋼絲垂下一條細固定線。紅、螢光藍、螢光黃以既有樹木種子決定，鏡頭移動不會換色；固定線從鋼絲高度連到下方枝幹，頂端加細小綁結。使用現有 Canvas 投影，不新增圖片或改植物位置與高度。

僅增加翡翠專用兩個繪圖函式與兩處呼叫；替換原本無色短吊線。更新 APP_VERSION 與頁面標題為 V15.17。城堡與其他溫室保持原有程式。
