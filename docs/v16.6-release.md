# V16.6 — Pick challenge plant proportions

Fixes the Emerald Greenhouse picking challenge's vertically stretched foliage. The previous renderer forced a complete 1024 × 1536 tree into a width of 115 screen units while independently scaling its height to 70% of the viewport. It also embedded decorative, unpickable fruit behind the live targets.

The challenge now assembles individually proportioned, transparent fig leaves around the existing nine nodes per plant, with tapered stems and bark detail. New photographic leaf and fig textures follow the supplied sunny greenhouse reference. All six plants retain their original positions. Leaf width and height share one scale, regardless of viewport height. The existing ripening colors tint the textured fruit, and every live target renders above the foliage. Static foliage and fruit color variants are cached.

Only plant rendering, two new assets, and the version label change. The roof, ground, aisle, HUD, UI, music, other scenes, tree lifecycle, difficulty, target centers and hit radii, scoring, and 45-second duration remain unchanged. Existing shared tree artwork is untouched.

Assets: `art/gh/pick-fig-leaf-v16.6.webp` and `art/gh/pick-fig-fruit-v16.6.webp`. Generated with the built-in image tool using the user's second image only as a botanical material and lighting reference, then resized and encoded for the site. Prompts requested one broad five-lobed realistic fig leaf with a bottom-center petiole, and one plump purple-red fig with a short top stem; both isolated on transparent backgrounds, natural sunlight, no scenery, character, text, or additional objects.

Validation: all 140 Node tests pass. `docs/pick-plants-regression.cjs` runs the actual challenge renderer and checks leaf aspect ratios across five viewport sizes, cached foliage, image-loading fallback, all six target positions across four phone sizes, green/overripe penalties, ripe scoring, and 45-second completion. Actual Canvas previews were rendered at 390 × 715, 390 × 844, 320 × 568, and 844 × 390 using the production function and assets. Inline scripts parse. No physical-phone or browser execution is claimed.
